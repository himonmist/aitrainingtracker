# Pharma AI Training Tracker

**LinkvisionSoft — AI Training Division**

A fully client-side, browser-based dashboard for tracking pharmaceutical AI training requirements, proposals, call logs, and action items.

## 🌐 Live Demo
**https://himonmist.github.io/aitrainingtracker/**

## ✨ Features
- 📊 Live management dashboard with KPI cards
- 📋 Training program tracker with status, priority & action due dates
- 📞 Call & meeting log with visual timeline
- 🏢 Client company directory
- ⚡ Action items tracker with overdue alerts
- 📂 Excel file upload — drag & drop your `.xlsx` tracker to refresh all data instantly
- 📱 Fully mobile responsive — sidebar collapses to hamburger + bottom nav on mobile
- 🔒 100% local — no server, no backend, all data stays in your browser

## 📂 How to Use
1. Open `index.html` in any modern browser
2. Click **"Load Excel File"** or drag & drop your `Pharma_AI_Training_Tracker.xlsx`
3. The dashboard refreshes from your Excel data instantly
4. Or click **"Explore with Demo Data"** to preview
